# Potato Leaf Disease Detection with Explainable AI (XAI)

## Overview
A deep learning-based system for detecting potato leaf diseases and explaining predictions using Explainable AI techniques.

## Features
- Potato disease classification
- CNN-based prediction
- LIME explanations
- Grad-CAM visualizations
- Disease confidence scores

## Technologies
- Python
- TensorFlow/Keras
- OpenCV
- LIME
- Matplotlib

## Dataset
PlantVillage Potato Leaf Dataset

## Results
- Healthy
- Early Blight
- Late Blight
